# לומדים כוזרי עם הרב בן ציון אוריאל

כל השיעורים על ספר הכוזרי — מההקדמה ועד סוף מאמר חמישי. 197 פרקים.

* **עמוד**: https://kuzari-pod.vercel.app
* **פיד**: https://kuzari-pod.vercel.app/feed.xml

## איך זה בנוי

| קובץ | תפקיד |
|---|---|
| `episodes.json` | מקור האמת. כל פרק: כותרת, תיאור, קובץ שמע, אורך, ותאריך הפרסום שלו. |
| `api/feed.js` | מייצר את ה‑RSS בכל בקשה, וכולל **רק** פרקים שתאריך הפרסום שלהם כבר עבר. |
| `index.html` | העמוד. קורא את `episodes.json` ומסנן באותה דרך בדפדפן. |
| Releases | קבצי השמע, release אחד לכל מאמר (`audio-m1` … `audio-m5`, `audio-bonus`). |

**אין כאן שום תהליך רקע ואין cron.** פרק "מופיע" מפני שבקשה לפיד הגיעה אחרי
התאריך שנקבע לו. אם אף אחד לא מבקש את הפיד — לא קורה כלום, וזה בסדר.

המטמון הוא 15 דקות.

## מה שווה לדעת

* **ה‑guid של 32 הפרקים הראשונים זהה למה שיש היום בספוטיפיי.** לכן אם מפנים את
  התוכנית הקיימת לפיד הזה, הפרקים הישנים לא ישוכפלו.
* **GitHub מגיש קבצי release כ‑`application/octet-stream`** ולא כ‑`audio/mpeg`.
  הנגנים הולכים לפי הסיומת ולפי `type` שבתג `enclosure`, וזה עובד — אבל אם פלטפורמה
  כלשהי מתלוננת, הפתרון הוא קידומת `https://dts.podtrac.com/redirect.mp3/` לפני
  כתובת השמע, כמו שנעשה ב‑`YeshivaPod`. (מ‑31/10/2026 הקידומת בפיד היא של OP3 — למטה.)
* 🚨 **ספירת ההאזנות — OP3 (31/10/2026, בקשת הרב אוריאל מס' 37, באישור רועי, באותם תנאים כמו
  שאר הפודקאסטים של הרב ב‑`~/uriel-emuna`):** בפיד, קובץ השמע עובר קודם דרך
  `https://op3.dev/e,pg=<podcast:guid>/github.com/…mp3` — שירות ספירה חינמי ופתוח שעונה 302 לאותו
  קובץ בגיטהאב ורושם כל בקשה. **אותו guid, אותו קובץ, אותו גודל** — פרק שכבר יצא לא מתחלף אצל
  המאזין. `<podcast:guid>` = UUIDv5 של `kuzari-pod.vercel.app/feed.xml` (`afb8f712-…`). הספירה
  עצמה (הורדה של אדם לפי הכללים המקובלים, בלי בוטים וסורקים) — `~/uriel-emuna/stats_op3.py`, והמספר
  מוצג ליד כל שיעור באתר השיעורים. `episodes.json` ו‑`index.html` לא השתנו — העמוד מנגן ישר מגיטהאב.
  * **המעקף כש‑OP3 נופל:** `const OP3 = ''` ב‑`api/feed.js`, ופריסה — הפיד חוזר לקישור הישיר מיד.
    `~/uriel-emuna/check.py` בודק את ההפניה כל בוקר.
  * **`lastBuildDate` הוא הפרק האחרון שיצא**, לא «עכשיו». עד 31/10 הוא היה «עכשיו» בכל בקשה, ולכן
    הפלטפורמות בדקו שוב ושוב את הפרק האחרון: 120–250 «הורדות» ביום בגיטהאב לפרק שאיש לא שמע.
  * בדיקה: `node ~/uriel-emuna/accounts-test/test-feed-kuzari-op3.js` (כל פרק שיצא, והמעקף).
* **מאמר שני שיעור 17** (מצוות ישוב הארץ להרמב"ם) לא היה בתיקיית הדרייב. הרב שלח
  את ההקלטה בוואטסאפ ב‑19/10/2026 והיא נכנסה במקומה (`~/kuzari-podcast/add_m2_17.py`):
  יוצא ב‑18/11/2026, וכל הפרקים שאחריו זזו מקום אחד בלוח. שום פרק שכבר יצא לא זז.
* שלושת השיעורים האחרונים של מאמר רביעי והאחרון של מאמר חמישי לא מופיעים במסמך
  «תוכן כל השיעורים», והנושא שלהם נקבע מהאזנה לדקות הפתיחה של ההקלטה עצמה.
