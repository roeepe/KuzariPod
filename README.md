# לומדים כוזרי עם הרב בן ציון אוריאל

כל השיעורים על ספר הכוזרי — מההקדמה ועד סוף מאמר חמישי. 196 פרקים.

* **עמוד**: https://kuzari-pod.vercel.app
* **פיד**: https://kuzari-pod.vercel.app/feed.xml

## איך זה בנוי

| קובץ | תפקיד |
|---|---|
| `episodes.json` | מקור האמת. כל פרק: כותרת, תיאור, קובץ שמע, אורך, ותאריך הפרסום שלו. |
| `api/feed.js` | מייצר את ה‑RSS בכל בקשה, וכולל **רק** פרקים שתאריך הפרסום שלהם כבר עבר. |
| `index.html` | העמוד. קורא את `episodes.json` ומסנן באותה דרך בדפדפן. |
| Releases | קבצי השמע, release אחד לכל מאמר (`audio-m1` … `audio-m5`, `audio-bonus`). |

**אין כאן שום תהליך רקע ואין cron.** פרק "מופיע" מפני שבקשה לפיד הגיעה אחרי
התאריך שנקבע לו. אם אף אחד לא מבקש את הפיד — לא קורה כלום, וזה בסדר.

## התזמון

פרק חדש בכל יום א׳–ה׳ בשעה 15:00 שעון ישראל, מ‑15/9/2026 עד 3/6/2027.
מדלג על חגים, חול המועד, ערבי חג, תשעה באב, פורים, ויום הזיכרון/העצמאות/השואה/ירושלים
(לוח `data/hebcal-*.json` ב‑`~/kuzari-podcast`, מ‑hebcal.com בלוח ישראל).

לשינוי תאריכים: לערוך `publish_at` ב‑`episodes.json` ולפרוס מחדש. הפיד מתעדכן מיד —
המטמון הוא 15 דקות.

## מה שווה לדעת

* **ה‑guid של 32 הפרקים הראשונים זהה למה שיש היום בספוטיפיי.** לכן אם מפנים את
  התוכנית הקיימת לפיד הזה, הפרקים הישנים לא ישוכפלו.
* **GitHub מגיש קבצי release כ‑`application/octet-stream`** ולא כ‑`audio/mpeg`.
  הנגנים הולכים לפי הסיומת ולפי `type` שבתג `enclosure`, וזה עובד — אבל אם פלטפורמה
  כלשהי מתלוננת, הפתרון הוא קידומת `https://dts.podtrac.com/redirect.mp3/` לפני
  כתובת השמע, כמו שנעשה ב‑`YeshivaPod`.
* **חסר שיעור אחד:** מאמר שני שיעור 17 (מצוות ישוב הארץ להרמב"ם) — אין לו הקלטה
  בתיקיית הדרייב. שאר המספור במאמר שני רץ ברצף בלעדיו.
* שלושת השיעורים האחרונים של מאמר רביעי והאחרון של מאמר חמישי לא מופיעים במסמך
  «תוכן כל השיעורים», והנושא שלהם נקבע מהאזנה לדקות הפתיחה של ההקלטה עצמה.

## בנייה מחדש

הכלים שמייצרים את `episodes.json` יושבים ב‑`~/kuzari-podcast`:
`build_episodes.py` (הרכבה) ו‑`upload_assets.py` (העלאת שמע ל‑releases, אידמפוטנטי).
