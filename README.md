# לומדים כוזרי עם הרב בן ציון אוריאל

הפיד המלא של הפודקאסט — כל השיעורים על ספר הכוזרי, מההקדמה ועד סוף מאמר חמישי.

* `episodes.json` — מקור האמת: כל פרק, הכותרת, התיאור, קובץ השמע ותאריך הפרסום שלו.
* `api/feed.js` — מייצר את קובץ ה‑RSS בזמן אמת, וכולל רק פרקים שתאריך הפרסום שלהם כבר עבר.
* השמע עצמו יושב ב‑Releases של המאגר הזה (release אחד לכל מאמר).

אין כאן שום תהליך רקע: הפרק "מופיע" מפני שבקשה לפיד מגיעה אחרי התאריך שנקבע לו.
